UltimateRealism — A high-end, open-source singleplayer overhaul engine for GTA V engineered for extreme visual and physical fidelity.

Built on a robust, zero-crash architecture, it features Advanced Kinematics for realistic terrain adaptation and foot placement, Environment Lighting with zero-GPU-cost shadow scaling, and a Performance Governor optimized for seamless 180Hz+ stability. Fully documented under the MIT License.
